# Blog2Social MCP Server

Blog2Social provides a hosted Model Context Protocol (MCP) server that
allows compatible AI assistants and agents to interact with Blog2Social.

## MCP Endpoint

https://api.blog2social.com/mcp

## Authentication

Blog2Social uses OAuth to authenticate users and authorize access to
their Blog2Social account.

## Documentation

https://docs.blog2social.com/api/#tag/Integrations/MCP

## Supported clients

The hosted MCP server can be used with MCP-compatible applications
including ChatGPT, Claude, Cursor, GitHub Copilot, n8n and others.

## Registry

This repository contains the metadata used to publish the Blog2Social
MCP server to the official MCP Registry.
